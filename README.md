## 🖨️ Printing & PDF Export Guide

To generate accurate single-page A4 PDFs:

1. Open `index.html` in your browser and click **Open CV** or **Print** on any design card (or open `cv-XX/index.html` directly).
2. Open the print dialog (`Ctrl + P` on Windows / `Cmd + P` on macOS).
3. Configure the following settings:
   - **Destination**: Save as PDF
   - **Paper Size**: A4 (`210mm × 297mm`)
   - **Margins**: None (or Default)
   - **Scale**: `100%`
   - **Background Graphics**: **Enabled** (Required to print background colors, sidebars, and badges)
   - **Headers and Footers**: **Disabled** (Removes browser URL and date footers)
